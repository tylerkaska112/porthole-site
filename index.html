New in 1.3.0

Sharper. Smoother.In real time.

Render low. Look sharp.

Upscaling enlarges the picture to your screen, so a game can run at a lower resolution and still look crisp. You can switch it on or off from the in-game menu while you play. Direct3D 11 and 12 games.

More frames from the same game.

Frame generation adds up to three frames between the ones the game draws. In Grand Theft Auto V that is 40 frames a second without it and 82 with it.

Controls

Play your way.

Touch controls that stay out of the way, an on-screen game controller, and full support for real controllers, keyboards and mice.

On-screen game controller

For games that need a pad. Xbox, PlayStation, Nintendo Switch and Super Nintendo styles, and the game simply sees an Xbox controller.

Trackpad mode

Slide to move the cursor, tap to click, tap with two fingers to right-click and drag two fingers to scroll. Made for point-and-click and strategy games.

A full PC keyboard

Function keys, arrows and all, with Shift, Ctrl and Alt that hold for the next key, so Ctrl+Shift+Z just works.

Everything in one place

A Controls page in Settings gathers every controller, keyboard, mouse and touch setting. Floating sticks and controls that fade away are one switch each.

      How it works

      Three steps to your first game.

      Install and set up

      Sign the app with your own certificate and install it, then follow the setup guide: switch on full speed, allow its private link, and download Microsoft’s Windows components.

      About 20 minutes the first time, then it’s done

      Add a game

      Sign in to Steam, Epic Games, GOG, itch.io, Amazon Games or EA and download one you own, or copy a game folder in from Files.

      As long as the download takes

      Press Play

      Check the game’s badge first if you like, then press Play. Tell other people how it went with a short report.

      The first start takes a minute or more

      Under the hood. Porthole is built on Madeira, a project that runs Windows programs on iOS by combining Wine, the FEX-Emu translator and DXMT, which turns Direct3D into Metal. Speed depends on the game and on the device, and some games need more memory than a phone has. It needs iOS 18 or later and JIT switched on, which Porthole can do by itself once it has a pairing file.

      Questions

      Good to know.

      Is Porthole on the App Store?
      No, and it can’t be: it relies on things Apple doesn’t allow in App Store apps. You install it yourself, signed with your own certificate. The Get it page explains how.
      Is it legal?
      Porthole contains no games and doesn’t bypass any copy protection. Steam games start through Valve’s own client files, which check your licence as they do on a PC; Epic, GOG and itch.io games are installed from the stores’ own servers with your own account; and Microsoft’s runtime is downloaded from Microsoft. Porthole is free software under the GPL and its source code is public.
      Which games will run?
      It depends on the game and the device. The compatibility list comes from reports sent by people using Porthole, and the app shows the same badge on each game.
      Can I use a keyboard and mouse?
      Yes, on an iPad. A Bluetooth or USB keyboard and a mouse or trackpad work in games like on a PC: every key, five mouse buttons, the wheel, the game’s own cursor in menus and a locked pointer for looking around. An iPhone gets a mouse only through AssistiveTouch. Details are in Help.
      Do I need a controller?
      No. Porthole has on-screen touch controls, including an on-screen game controller, and on an iPad a keyboard and a mouse work too. A controller makes it feel like a console, and Porthole shows which games support one.
      Do upscaling and frame generation cost extra?
      They use Lossless Scaling, which you need to own on Steam. Porthole checks your Steam purchase and keeps nothing of Lossless Scaling that you did not buy.
      Was this built with AI?
      Yes. A large part of the code, the documentation, this website and the artwork was written by an AI coding assistant (Claude, from Anthropic) working with the maintainer, who directs the project, reviews the changes and tests them on real devices. The project therefore contains AI-written code, and like any software it may contain mistakes.
      Does it collect my data?
      No account, no ads and no tracking. A compatibility report is only sent when you choose to send one. The privacy page lists exactly what a report contains.
      Is it affiliated with Valve, Microsoft or Apple?
      No. Steam and its artwork belong to Valve; Epic Games, GOG and every game or launcher you run belong to their owners. Apple, iPhone, iPad and iOS are trademarks of Apple Inc.
