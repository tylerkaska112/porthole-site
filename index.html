For iPhone and iPad

Windows PC games, in your pocket.

Porthole runs Windows games on your iPhone and iPad. Bring your own game files, download the ones you own on Steam, and see how each game runs on phones like yours before you try it.

What it does

Everything in one place

Add games your way

Copy a game folder in from the Files app, or run a Windows installer. Porthole finds the right program in the folder and keeps uninstallers and helper tools out of the way.

Your Steam library

Sign in and download the Windows games you own. They start through Steam itself, so your licence is checked the normal way.

Built for a controller

Move around the whole app with a game controller, like a console. Steam says which games support one, and Porthole shows it on every game.

Know before you try

Each game shows a badge from reports by other people: works great, works with problems, or doesn't work. Add your own in under a minute.

Made for iPhone and iPad

Touch controls you can switch while you play, a page for every game with its own settings, and a layout that fills the iPad screen.

No ads, no account

Porthole has no ads and no account of its own. A compatibility report is only sent when you choose to send one, and nothing in it names you.

Made to be used with a controller

A shelf that feels like a console

Your games sit on one row. Move along it and the one you're on grows, with its name, its badges and Play right there.

How it works

Three quick steps to your first game

  1. Get ready

    Install Porthole and follow the setup guide: switch on full speed, allow its private link, and download Microsoft's Windows components.

  2. Add a game

    Sign in to Steam and download one you own, or copy a game folder in from Files.

  3. Press Play

    Check the game's badge first if you like, then press Play. Tell other people how it went with a short report.

Under the hood Porthole is built on Madeira, a project that runs Windows programs on iOS by combining Wine, the FEX-Emu translator and DXMT, which turns Direct3D into Metal. Speed depends on the game and on the device, and some games need more memory than a phone has. It needs iOS 18 or later and JIT switched on, which Porthole can do by itself once it has a pairing file.

Straight talk

What to expect

It's early

Porthole is a hobby project that changes often. Plenty of games don't run yet, and some run slowly. The compatibility list shows what people have actually tried.

It takes some setting up

Porthole isn't on the App Store, because it uses interfaces Apple keeps private. You sign the app file with your own developer certificate and install it yourself. Here's what you need.

You bring the games

Porthole never includes games and doesn't get around any copy protection. You need to own what you run.

Questions

Good to know

Is Porthole on the App Store?

No, and it can't be: it relies on things Apple doesn't allow in App Store apps. You install it yourself, signed with your own certificate. The Get it page explains how.

Is it legal?

Porthole contains no games and doesn't bypass any copy protection. Steam games start through Valve's own client files, which check your licence as they do on a PC, and Microsoft's runtime is downloaded from Microsoft. Porthole is free software under the GPL and its source code is public.

Which games will run?

It depends on the game and the device. The compatibility list comes from reports sent by people using Porthole, and the app shows the same badge on each game.

Do I need a controller?

No. Porthole has on-screen touch controls, and a keyboard works too. A controller makes it feel like a console, and Porthole shows which games support one.

Does it collect my data?

No account, no ads and no tracking. A compatibility report is only sent when you choose to send one. The privacy page lists exactly what a report contains.
