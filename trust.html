Trust

Why you can trust Porthole, and where its limits are

Porthole is a one-person project that asks for a lot: your game store sign-ins and a certificate you sign apps with. This page says what protects them, and what doesn't. Last updated 13 October 2026.

You can read the code

Porthole is free software under the GNU General Public License, and its source code is public, together with notes on how to rebuild it and the exact versions of the engine it uses. A build you make yourself has nothing of the maintainer's in it.

Updates are signed

Every release is signed with a key that stays on the maintainer's own computer. The released app carries the matching public half and installs an update only if its signature is valid and the download matches the signed checksum. Someone who tampered with the update server could not hand your copy a build the maintainer never made. (A build you compile yourself has no maintainer key, so it does not check.)

Your logins

  • Sign-in tokens for Steam, Epic Games, GOG and itch.io are kept in the iOS Keychain, readable only on this device. They are never written to a file the app shares, never logged, and sent only to the store itself.
  • Your passwords are not kept. Epic and GOG passwords are typed on the store's own page, and Steam's is encrypted before it leaves the device and forgotten.
  • Store traffic is kept out of iOS's network cache, and sign-in pages keep no cookies.
  • Pairing files, certificates and profiles you pick are deleted from temporary storage as soon as they are read.

What is collected

No analytics, no ads, no account. A compatibility or problem report is sent only when you choose, and a problem log is cleaned of account names, e-mail addresses and public IP addresses first. Everything is listed on the privacy page.

What has been checked

On 13 October 2026 the author went through the app and the update server looking for ways logins and personal data could leak, with the help of AI. What was found was fixed: store tokens kept out of the network cache, picked files deleted after use, signed updates, a server crash on a malformed address, and tighter file permissions on the server. This was not an audit by an outside firm.

Where the limits are

  • Games run inside Porthole's own process. Windows programs can read the app's files, which is why secrets are kept in the Keychain and not in files. A program written on purpose to attack Porthole could still try to read the app's memory. Only run games you got from a store you trust.
  • You sign the app yourself. Porthole can't be installed from the App Store, so whoever provides the certificate (your own account or a third-party service) can see and sign what you install, and a third-party certificate can be revoked. Choose one you trust.
  • It is a hobby project made with AI help, tested by one person on a few devices. Expect bugs.

Not affiliated

Porthole isn't affiliated with Valve, Epic Games, GOG, itch.io, Microsoft or Apple. It contains no games and doesn't bypass any licence check or copy protection: Steam games start through Valve's own client files, which check your licence as they do on a PC.

Found a security problem?

Please use GitHub's private Report a vulnerability button under the repository's Security tab, so it can be fixed before it is public. Other questions: the Discord.
