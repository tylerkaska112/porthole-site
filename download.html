Get Porthole

Porthole isn't on the App Store, and can't be: it uses interfaces Apple keeps private. You download an app file (an IPA), sign it with your own developer certificate, and install it. The first time takes about 20 minutes and it isn't for everyone, so read this page first.

Early hobby project. Many games don't run. Check the compatibility list for the games you care about before you spend an evening on it.

You need

  • An iPhone or iPad with iOS 18 or later. More memory is better.
  • A way to sign and install apps yourself, with a development certificate and profile that include Network Extension (packet tunnel), Personal VPN, Increased Memory Limit, Extended Virtual Addressing and get-task-allow. Apple normally only gives these to a paid Apple Developer account.
  • JIT switched on for the app. Porthole can do it itself once it has a pairing file, and on iOS 27 or later it can make that file on the device.
  • Games you own: Steam games you can sign in to, or game folders and installers you copy in from the Files app.

Download

The first public release isn't out yet. When it is, the IPA, its checksum and the source code will be here, on the project's GitHub Releases page:

All releases on GitHub

You can also download every build, current and past, from inside Porthole under Settings ▸ Updates. Without a certificate added it saves the file for you to sign yourself.

Which certificate to use

The certificate and profile you sign with decide how well Porthole works, so this is worth getting right.

  • Best: your own development certificate and profile from a paid Apple Developer account. The profile must include get-task-allow (that is what lets Porthole switch JIT on) and Network Extension (packet tunnel), Personal VPN, Increased Memory Limit and Extended Virtual Addressing, for the app and for each of its two extensions.
  • Keep the .p12 and its password. With them Porthole signs every new version of itself on your device; without them you can still download new versions as a file and sign them yourself.
  • A free Apple ID usually is not enough. It cannot add those capabilities and its profiles expire after about a week.
  • Be careful with signing you do not control. A shared or third-party certificate can be revoked without warning, may lack these capabilities, and means someone else signs an app that holds your Steam sign-in and your games.

Apple changes its account limits from time to time. Check Apple's current developer documentation for the exact numbers.

Install

  1. Download the IPA and check the checksum.
  2. Sign the app and its two extensions with your certificate and profiles, keeping the bundle ids in step (your.id, your.id.jithelper, your.id.tunnel), and install it.
  3. Open Porthole and follow the setup guide: full speed (JIT and the private link), Microsoft's Windows components, and your games.

The full guide, including the exact requirements for each part, is in the INSTALL document in the source repository.

Is it legal and safe?

Porthole contains no games and doesn't get around any copy protection: Steam games start through Valve's own client files, which check your licence as they do on a PC. Microsoft's runtime is downloaded from Microsoft. Porthole is free software under the GPL, and its source code is public. It is not affiliated with Valve, Microsoft or Apple. Privacy
