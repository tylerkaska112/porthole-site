Get it

Get Porthole

Porthole isn't on the App Store, and can't be: it uses interfaces Apple keeps private. You download an app file (an IPA), sign it with your own developer certificate, and install it. The first time takes about 20 minutes and it isn't for everyone, so read this page first.

Early hobby project. Many games don't run. Check the compatibility list for the games you care about before you spend an evening on it.

Stuck at any step? Ask in the Discord: the support channels are made for exactly this.

You need

  • An iPhone or iPad with iOS 18 or later (tested on iOS 26 and 27). More memory is better.
  • A way to sign and install apps yourself. A paid Apple Developer account or a third-party certificate service is recommended: both can provide every capability Porthole uses (Network Extension, Personal VPN, Increased Memory Limit, Extended Virtual Addressing and get-task-allow). A free Apple ID also works, with some features missing (see below).
  • JIT switched on for the app. Porthole can do it itself once it has a pairing file, and on iOS 27 or later it can make that file on the device.
  • Games you own: games from Steam, Epic Games, GOG or itch.io that you can sign in to, or game folders and installers you copy in from the Files app.

What Porthole can't run

Better to know before you spend an evening on it. These don't work, or mostly don't yet:

  • Games with kernel-level anti-cheat. Windows' driver-level protections have nothing to run on here.
  • Very large programs. The runtime copies a program into a fixed memory area, so executables of roughly 450 MB and up can't load.
  • Games that need more memory than your device has. Swap helps some, not all.
  • Games that need a launcher of their own. Epic's overlay and anti-cheat, GOG Galaxy's online features, and other publishers' launchers (such as Ubisoft's or Rockstar's) mostly don't run yet.
  • Programs that use Windows features that aren't implemented yet. Some Unity games only work when started through Steam.

Not sure about a game? Look it up on the compatibility list or ask on the Discord.

Which certificate to use

The certificate and profile you sign with decide how well Porthole works, so this is worth getting right.

  • Recommended: a paid Apple Developer account, or a third-party certificate service. Either can provide a profile with get-task-allow (that is what lets Porthole switch JIT on) and Network Extension (packet tunnel), Personal VPN, Increased Memory Limit and Extended Virtual Addressing, for the app and for each of its two extensions. That is the complete install, with nothing given up.
  • A free Apple ID works, with a lighter install. It cannot carry the VPN (Network Extension) capability, so you run LocalDevVPN for the private link, and it cannot carry Increased Memory Limit, so memory-hungry games are more likely to run out of memory. Its signing also expires after about a week, so you sign again weekly. Porthole's Settings tell you exactly what your install is missing and what that costs.
  • Keep the .p12 and its password. With them Porthole signs every new version of itself on your device; without them you can still download new versions as a file and sign them yourself.
  • Choose who signs with care. A third-party service can revoke its certificate, and it is the one signing an app that holds your store sign-ins and your games, so pick one you trust. Keep a copy of the IPA you installed.

Apple changes its account limits from time to time. Check Apple's current developer documentation for the exact numbers.

Install

  1. Download the IPA and check the checksum.
  2. Sign the app and its three extensions with your certificate and profiles, keeping the bundle ids in step (your.id, your.id.jithelper, your.id.tunnel, your.id.activity), and install it. Short on App IDs? Each extension can be left out; the INSTALL guide says what that costs.
  3. Open Porthole and follow the setup guide: full speed (JIT and the private link), Microsoft's Windows components, and your games.

The full guide, including the exact requirements for each part, is in the INSTALL document in the source repository.

Is it legal and safe?

Porthole contains no games and doesn't get around any copy protection: Steam games start through Valve's own client files, which check your licence as they do on a PC. Microsoft's runtime is downloaded from Microsoft. Porthole is free software under the GPL, and its source code is public.
