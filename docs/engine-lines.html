Engine lines

SearchSettingsEngine linesErrors and log linesMessages

Engine lines change how the Windows layer underneath Porthole behaves, for example swap-coverage = wide or env.MADEIRA_FEX_AVX = 1. There are 835 of them. Most games need none.

How to use one

  1. Open the game in Porthole and go to its settings.
  2. Under Starting, tap This game’s engine lines.
  3. Type the line, one per line, in the form key = value, then start the game again.

A line there applies to that game only and wins over the app-wide madeira.cfg. A line that starts with env. sets an environment variable for the game. These are for finding and working around problems; a wrong value can stop a game from starting. Remove the line to undo it.

avail-phys On/off

Report the memory left before the app's limit as available

Default off. 1: Windows programs' available physical memory (GlobalMemoryStatusEx) is what remains before Madeira's memory limit instead of the phone's free memory, so Chromium (Social Club, Steam) frees caches below 1000 MB and 400 MB left, and a game can see memory running out. Set it in the game's own file; read at session start.

Type: On/off · Default: 0

avail-phys-cef-mb Number

Available memory Chromium sees (MB)

0 (default): off. N: Social Club's SocialClubHelper.exe and Steam's steamwebhelper.exe see at most N MB of available physical memory, nobody else (the game and the launcher keep the real figure). Below 400 (e.g. 300) Chromium reports critical memory pressure every 5 s and purges caches and garbage; 400-999 (e.g. 900), moderate every 10 s. Independent of avail-phys. Set it in the game's own file; read at session start.

RAM for the swap tier that is not counted against Madeira's limit, donated by the MadeiraMemoryHost extension (512 MB regions, created untouched, handed over, then the extension exits).
