Install check

JIT cannot be switched on

This copy was signed without the “debuggable” permission (get-task-allow), which comes with a distribution or enterprise certificate. No tool can turn JIT on for it. Sign it with a development certificate and profile.

JIT can be switched on

This copy is signed so a debugger may attach.

Extra memory allowed

Games may use more memory than a normal app.

Extra memory is not allowed

Big games may close on their own without warning.

Large address space allowed

Games can map the memory the engine reserves for them.

Large address space is not allowed

Some games will not start, or close shortly after they do.

… was signed without the “Network Extensions” permission, so iOS will not run Porthole's own tunnel. You do not need it: use LocalDevVPN instead (turn on “Use LocalDevVPN instead” in Settings › JIT and connection, and switch LocalDevVPN on before you press Play)\(usingLocalDev ?

The private link was signed by another team

The tunnel extension and the app were signed with different profiles, so iOS will not start it. Sign both with the same certificate and team.

The private link can start

The tunnel extension carries the Network Extensions permission.

No private link inside this install

Run LocalDevVPN when a tool needs the private link to switch JIT on. Porthole does not start its own VPN, so your own VPN is left alone.

The JIT helper has no signature

iOS will not run the JIT helper. Install again so both the app and the helper are signed.

The JIT helper's profile has expired

Sign Porthole again to renew it.

No JIT helper inside this install

Switch JIT on with StikDebug or another tool. “Porthole does it” is not available in this install.

No download card extension inside this install

Downloads show iOS's own download card (percentage, size and speed) instead of the one with Pause and Cancel buttons. It saves an App ID.

Donor memory can start

The Memory Host extension is inside and signed.

No donor memory extension inside this install

Settings > Advanced > Engine options > Memory > Donor memory does nothing in this install. It saves an App ID.

Donor memory cannot start

The Memory Host extension is inside, but …, so iOS will not run it. Sign Porthole again, or install without it to save an App ID.
