Settings

Advanced

Options

Show technical options Toggle

Shows swap and video memory, shader math, tunnel and JIT status, and technical readouts. Most people never need them.

Bigger code pool when the game allows it Toggle

The emulator keeps a stretch of memory free for the rare game that can only load at one fixed address. When none of a game's programs needs it, this gives it back so the code pool can be larger (fewer freezes in big games). Turn it off to go back to the previous behaviour if a game that started before no longer does.

Components

Runtimes

Programs many games need and Windows would normally have. Each is a one-time download, checked against a fixed fingerprint before it is used.

Visual C++ runtime Action

Microsoft's runtime that many games need. About 25 MB, downloaded from Microsoft's own installer and checked against a fixed fingerprint before anything is used. Without it some games won't start.

Remove the downloaded copy Action

No further description in the app.

.NET Framework (Wine Mono) Action

Games built on Microsoft's .NET Framework (Celeste, many indie games and launchers) run on Wine Mono, the Wine project's open-source .NET runtime. About 42 MB from WineHQ, about 130 MB once installed, checked against a fixed fingerprint before use. Without it those games end as soon as they start.

Remove Wine Mono Action

No further description in the app.

32-bit Visual C++ runtime Action

Microsoft's C++ runtime for 32-bit programs (older games, many launchers). Without it they run on Wine's own C++ runtime. About 14 MB from Microsoft's installer, checked against a pinned fingerprint and unpacked here; every file is checked again. Not allowed while a game is running.

Remove the 32-bit runtime Action

No further description in the app.

Web pages in programs (Wine Gecko) Action

Installers and launchers that show a web page use Wine Gecko, the Wine project's open-source web engine. About 110 MB from WineHQ (a 32-bit and a 64-bit file), checked against fixed fingerprints before use. Without it Wine stops on its own “Wine Gecko Installer” window, whose download can hang. Programs that already installed it keep it.

Remove Wine Gecko Action

Fixing problems

When a game stops and its log clearly shows a known cause, Porthole can suggest changing one setting of that game. By default it asks first and changes nothing until you say yes. It never touches app-wide settings and you can undo a change. Nothing is sent anywhere.

Look for known problems Toggle

Examples: a game that needs AVX could get AVX turned on; a game that ran out of memory could get a swap file. Porthole reads the game's log after it stops and shows what it found on the Home screen. A game gets each fix once.

Ask me before changing a game Toggle

On (the default): a fix is only suggested, with Apply on the Home screen, and nothing about the game changes until you tap it. Off: the fix is made at once and the Home screen shows it with an Undo button.

Connection Extras

Connection to this device

The JIT helper reaches this device through a private connection. Porthole can make its own, or you can use LocalDevVPN; you only need one.

Use LocalDevVPN instead Toggle

Does not start this app's own tunnel. LocalDevVPN (or another VPN with the same 10.7.0.x addresses) has to be switched on before you press Play; it keeps running while the game does. Turn this on if the app's own tunnel sometimes fails to come up. Off: the app starts and stops its own tunnel, which replaces any other VPN while it is on.

Your own VPN

iOS runs one VPN at a time, so yours is paused while JIT is switched on.

Ask before pausing it Toggle

iOS runs one VPN at a time, so Porthole's tunnel switches yours off while a game starts or an update installs. With this on, Porthole asks first.

Shortcut to turn it back on TextField

iOS does not let an app start another app's VPN. To get it back automatically: open the Shortcuts app, make a shortcut with one action, Set VPN (choose your VPN, then Connect), and type its exact name here. When your game closes or the update is done, Porthole runs it, then returns here. Leave this empty and Porthole just reminds you. A VPN with Connect On Demand switched on in its own app comes back by itself.

Turn it back on as soon as JIT is on Toggle

With a shortcut above, your VPN comes back right after JIT is switched on, before the game starts, instead of when the game closes. Use this on a network that blocks Steam, so the game's Steam sign-in goes through your VPN. Porthole leaves the app for a moment to run the shortcut, as it does for cellular data.

Make the shortcut Action

Shortcuts can't be created for you: iOS only accepts shortcut files signed by Apple, and the Set VPN action has to point at your own VPN, which only you can pick. This opens a new, empty shortcut. Tap Add Action, search for Set VPN, choose your VPN and set it to Connect, then tap the name at the top and call it Porthole VPN. Porthole fills in that name for you.

Cellular data

The private connection does not work while cellular data is the network in use.

Switch cellular data off when needed Toggle

Porthole's private connection (JIT, and installing an update on this device) does not work while cellular data is the network in use. It needs no internet, so with this on, Porthole asks, switches cellular data off for a few seconds with a Shortcut, and switches it back on as soon as it is done. On Wi-Fi nothing happens.

Add the two shortcuts Action

iOS only lets an app switch cellular data through a Shortcut with the action Set Cellular Data. These two are bundled with Porthole, signed so iOS accepts them, and contain only that one action. Do not rename them.

Test the shortcuts Action

A quick check that both shortcuts are added and allowed, so the first real use does not stop to ask. It works on Wi-Fi too.

Game Engine

Compatibility

AVX and AVX2 Override

Lets the translator run programs built for AVX processors through its 128-bit emulation. A game that closes the moment it starts, or after a message about unsupported instructions, may need it. Only 64-bit games. Costs some speed.

Upscaling (MetalFX) Override

Enlarges the picture the game draws with MetalFX’s spatial scaler instead of the screen’s plain stretch. “To the screen” works out the factor itself: it enlarges the game’s picture to the screen’s own pixels (at most 2×) and does nothing when the game already draws about as large as the screen. It pays off when the game draws smaller than the screen: set this game’s Resolution (Settings or the game’s Display row) to what you want it to draw at, for example 1280×720, and the game gets faster while the picture stays sharp. A fixed factor is there for testing. Direct3D 11 and 12 games. This is what the game starts with: the in-game menu (Upscaling) changes it while the game runs, and remembers the choice for this game. It works together with Lossless Scaling frame generation: the generated pictures are enlarged the same way. Needs a device with MetalFX.

Upscaling method Override

What enlarges the picture. MetalFX is Apple’s spatial scaler. Lossless Scaling LS1 is the upscaler of your copy of Lossless Scaling: a small neural network that redraws the edges; the performance version uses a lighter network. Direct3D 11 and 12 games. The in-game menu changes it while the game runs.

Upscaler sharpness Override

1 is the softest, 5 the sharpest (and can look over-processed).

Lossless Scaling frame generation Override

Makes the pictures between the game’s own frames with Lossless Scaling’s motion-estimation shaders (from your copy of the program, set up under Stores > Lossless Scaling), so the screen can show more frames than the game draws. Like the MetalFX version it needs a screen that can run faster than the game (on a 120 Hz screen a game at 60 FPS or less), shows the game as it is when it cannot, adds about half a game frame of delay and works for Direct3D 11 games and, since 1.3.92, Direct3D 12 games too (they need more memory: the passes keep a few full-size pictures). The first seconds of a game stutter while the shaders are prepared. Not together with the MetalFX frame generation (this one wins). Experimental.

Frames added between two Override

How many pictures are made between two of the game’s own. Each one needs its own run of the passes, so 2 and 3 cost much more graphics work than 1 and slow the game itself down. More frames also need a faster screen.

CPU cores reported Override

How many processor cores this game is told about. Some games size their worker threads from it.

Direct3D 9 anisotropic filtering Override

Limits (or raises) texture filtering quality for Direct3D 9 games. The game's own setting is used by default.

Reduced-precision x87 Override

Makes old floating-point instructions faster and less exact. The engine turns it on by itself for 32-bit games; Off asks for full precision, which some games need (Assassin's Creed's character cannot be moved with the left stick otherwise). Leave it alone for games that run well.

Graphics card the game sees Override

Which graphics card this game is told it has, everywhere it can ask: Direct3D 9, 10, 11 and 12, Windows' own adapter list and NVIDIA's NVAPI. For a game that refuses to start or picks poor settings because it does not know the card, or that needs an NVIDIA one. This changes only what the game reads; the device draws the same.

Large memory reservations Override

Turn this on when a game quits at start because it reserves far more address space than iOS gives the app (64 GB or more, as Final Fantasy Tactics - The Ivalice Chronicles does). Porthole then really backs 16 GB of it and tells the game it got everything. Off (the default) leaves such a reservation to fail, as before.

Graphics route (Vulkan, experimental)

Which layer turns this game's Direct3D into the GPU's own language. Each row starts on Default, which is the normal route (DXMT and madeira-d3d12, both on Metal). Try a Vulkan route for a game that draws wrongly or crashes, or to compare speed.

Direct3D 10/11 runtime Override

Default is DXMT, which runs Direct3D 10 and 11 on Metal. DXVK runs them on Vulkan instead (through MoltenVK or KosmicKrisp). Experimental and off unless you choose it; 64-bit games only. DXVK is used together with vkd3d-proton for Direct3D 12.

Direct3D 12 runtime Override

Default is madeira-d3d12, which runs Direct3D 12 on Metal. vkd3d-proton runs it on Vulkan instead. Experimental and off unless you choose it; 64-bit games only.

Vulkan library Override

The library the Vulkan routes (and OpenGL through Zink) use. MoltenVK is Khronos' translator and the default when Vulkan is needed. KosmicKrisp is Mesa's Vulkan 1.4 driver for Metal 4: it needs iOS 26 or later and a newer device, and may support more of what DXVK asks for.

One-time installs

One-time installs Choice

Some Steam games bring installers for things they need (Rockstar's launcher, DirectX, Visual C++). Run at next start runs the ones that have not run yet before the game starts, with Windows' service manager available to them; after that the choice goes back to Skip, so they do not run every time. Skip starts the game without them. Use Run at next start again to retry an installer that failed.

Run them all again Action

Forgets that this game's one-time installs ever ran, so the next start runs every one of them again (Rockstar's launcher, Social Club, DirectX, Visual C++). Use it after you deleted what they installed, or when an install stopped half way. It does not delete anything itself.
